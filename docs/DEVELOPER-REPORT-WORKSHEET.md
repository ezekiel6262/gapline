# Questions for your own developer-experience report

This is a blank preparation worksheet, NOT a report to submit. The hackathon rejects AI-generated reports. Write your answers yourself from your personal experience; do not copy generated narratives or let an assistant invent your experience.

Use the official form: https://forms.gle/EUQ39xf54GHjC2ys5

1. When did you start onboarding, and when did you personally get your first successful API call? What delayed you?
2. Which exact documentation URL and section did you find wrong or unclear? What did you expect and observe?
3. Which API errors or edge cases did you encounter? Include exact endpoint/code/time from your own logs, with credentials removed.
4. What did you personally experience when using Wallet Skills, Agentic Wallet or the CLI? What was useful or missing?
5. What did you actually observe about tokenized-stock liquidity, slippage and behavior outside traditional hours? Separate measurements from assumptions. Do not claim you tested an issuer you did not test.
6. What concrete changes would make first-call setup simpler?
7. Which capabilities would you request, and why?

Check every factual statement yourself. Do not include API keys, signatures, login tickets, wallet session tokens or private keys. No answers have been filled in by AI.
